## Slide 4 — PROPOSED: Reporting

**Eyebrow:** PROPOSED SYSTEM PROCESS FLOW  
**Title:** Proposed Reporter Reporting

**Flow:**  
**Start** → Open **app / website** → **Make Report** → **PIN** + pick equipment (room / QR) → fill issue + photo → **Submit** → shows in **Maintenance** queue → **END**

## Slide 5 — MANUAL: Maintenance

**Eyebrow:** CURRENT MANUAL PROCESS FLOW  
**Title:** Manual Maintenance Response

**Flow:**  
**Start** → Write in **notebook / Excel** → check Urgent or not → go **on-site** →  
**Fix?** Yes → repair by hand · No → tell **Purchaser** to replace →  
tell reporter **personally** → **END**

---

## Slide 6 — PROPOSED: Maintenance

**Eyebrow:** PROPOSED SYSTEM PROCESS FLOW  
**Title:** Proposed Maintenance Response

**Flow:**  
**Start** → Ticket in system (or walk-in logged) → Maintenance starts **Processing** →  
**Fixable?**  
- **Yes** → mark **Resolved** (+ proof)  
- **No** → mark **For Replacement** (Purchaser notified)  
→ Reporter sees **status** → **END**

---

## Slide 7 — MANUAL: Procurement

**Eyebrow:** CURRENT MANUAL PROCESS FLOW  
**Title:** Manual Procurement

**Flow:**  
**Start** → Paper **RIS** → chase signatures → paper **ATP / check request** → Accounting paper **DV** → get check → buy → paper **RR** → (cash advance) paper **liquidation** → **END**

---

## Slide 8 — PROPOSED: Procurement (one cycle)

**Eyebrow:** PROPOSED SYSTEM PROCESS FLOW  
**Title:** Proposed Procurement One-Cycle  
**Banner:** Request No. `PR-YYYYMM-####`

**Flow:**  
**Start** →  
1. **Purchaser** makes Canvass+RIS → **School Admin** (optional **President**)  
2. Purchaser sends to **Supply Officer** → ATP → School Admin → back to Purchaser  
3. Purchaser **RFC** → School Admin  
4. Purchaser → **Accounting** DV → School Admin → **President** → check release → Purchaser collects  
5. Purchaser buys + OR → **RR** → **Receiving** second check  
6. If **Cash Advance** only → Purchaser **Liquidation**  
→ **END**
